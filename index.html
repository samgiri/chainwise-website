8-Layer Detection Framework

Layer 1: Patterns

Guaranteed returns, MLM language, unsustainable APY

Layer 2: Bytecode

Dangerous functions, owner controls, time-locks

Layer 3: Treasury

Fund flows, outflows, mixer transfers, drain velocity

Layer 4: Withdrawals

Pause events, queue depth, cooldowns, collapse signals

Layer 5: Bridges

Cross-chain tracking, bridge monitoring, exit detection

Layer 6: Off-Ramps

CEX proximity, VASP detection, operator exit paths

Wallet clustering, timing analysis, coordinated behavior
